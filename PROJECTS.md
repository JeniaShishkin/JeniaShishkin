# Projects

A collection of C++ and Python projects covering systems programming, graphics, concurrency, and AI-powered applications.

## [ASCII Drawings](https://github.com/JeniaShishkin/ascii-drawings)
- C++ library and demo for drawing shapes on an ASCII terminal canvas.
- Includes line and circle drawing, colored canvases, and coordinate-based plotting.

## [C++ Linked List Practice](https://github.com/JeniaShishkin/cpp-Linked-list-practice)
- Implements a singly linked list and iterator in C++.
- Supports basic operations such as adding and removing elements, copying, and iteration.

## [Drone Simulator](https://github.com/JeniaShishkin/Drone-Simulator)
- Modular C++ drone simulator with a grid-based world, navigation, and movement commands.
- Includes interchangeable sensors, tiles, and an energy system.
- Uses SOLID principles and a command-oriented architecture; also includes a networking layer for remote interaction.

## [E-Commerce Product Deduplication](https://github.com/JeniaShishkin/e-commerce-product-deduplication)
- Python tool that groups catalog products by SKU and keeps the lowest-priced entry in each group.
- Reads and writes CSV data and supports product names in multiple languages.

## [Memory Allocator](https://github.com/JeniaShishkin/Memory-Allocator)
- Learning-focused C++ allocator that manages a contiguous memory buffer.
- Uses first-fit allocation, splits blocks for smaller requests, and coalesces adjacent free blocks.
- Protects allocator operations with a mutex.

## [MyString](https://github.com/JeniaShishkin/MyString)
- Implements a custom C++ string class with dynamically managed character storage.
- Provides copy and move construction, comparison, concatenation, indexing, and stream output.

## [RAG-Based Movie Script Q&A System](https://github.com/JeniaShishkin/RAG-Based-Movie-Script-QA-System)
- Answers natural-language questions using retrieved excerpts from movie scripts.
- Loads and chunks scripts, stores embeddings in Qdrant, and retrieves relevant context for answer generation.

## [Random Number Generator Pipeline](https://github.com/JeniaShishkin/Random-number-generator-pipeline)
- C++ multithreaded pipeline that generates random numbers, removes duplicates, filters for primes, and prints results.
- Uses blocking cyclic queues and thread pools to connect concurrent processing stages.

## [Research AI Agent](https://github.com/JeniaShishkin/research-AI-Agent)
- Python research assistant that uses an LLM and tools to investigate a user-provided topic.
- Produces structured results with a topic, summary, sources, and tools used.

## [Simple Ray Tracer](https://github.com/JeniaShishkin/SimpleRayTracer)
- C++ graphics project that renders a scene into an image and displays it in an SDL window.
- Uses Eigen for vector and matrix operations.
